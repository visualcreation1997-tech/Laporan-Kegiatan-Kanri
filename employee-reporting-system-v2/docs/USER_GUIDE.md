# User Guide

1. Login.
2. Select employee/month as permitted by the account.
3. Load the selected report.
4. Add daily activities and photos.
5. Add attendance and photos.
6. Review the list.
7. Submit the report.
8. Admin reviews the submitted report.
9. Admin approves it or requests revision.
10. Generate the Word report after the data is complete.

For the full end-user guide, use the separate PDF manual maintained with the project.
