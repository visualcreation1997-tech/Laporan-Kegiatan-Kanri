# Portfolio Presentation

Recommended order for a recruiter:

1. README — problem, solution, stack.
2. Architecture diagram — system components.
3. `docs/ARCHITECTURE.md` — technical design.
4. `database/schema.sql` — relational model.
5. `database/rls-policies.sql` — authorization approach.
6. `src/app.js` — implementation.
7. `docs/WORKFLOW.md` — business workflow.
8. `docs/RECRUITER_GUIDE.md` — resume traceability.

This makes the repository read like a real engineering project rather than a single HTML demo.
